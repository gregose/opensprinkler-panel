OpenSprinkler panel firmware

The classic-ESP32 CYD and Waveshare ESP32-S3 panels are supported. Connect the panel over USB, then flash the merged CI image over WebSerial. The release flasher detects the connected chip automatically. This single-board CI artifact contains the firmware for the environment named in the artifact.

If you opened this page from the downloaded CI artifact, keep merged-firmware.bin one directory above this page so the manifest can find it.
