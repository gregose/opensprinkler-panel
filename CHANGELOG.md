## [1.0.0] - 2026-07-27

Initial public release. A 3.5" touch panel that runs and steps your
OpenSprinkler stations and programs locally over the controller's HTTP API —
no phone, app, or cloud. Includes manual station control with auto-advance, a
Programs view with a live run queue, browser-based flashing, over-the-air
updates, and a hosted user manual.

See the documentation for supported hardware and full details.
