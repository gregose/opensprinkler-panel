OpenSprinkler · Local Station Control

Station control panel — UX design doc

One screen. When nothing's running it asks you to pick a station; tap one and it runs. From there you can Advance, Stop, or jump to any station, and a single Auto-advance switch decides whether the run time ending means stop or roll to the next. Adjust the run time mid-run to extend the station you're on. Tap through the live model — including your real 14 stations, and the 24 your extender allows.

02 The interaction

    
Idle and running are two clean states — the panel only ever shows the controls that make sense right now.

    

      
Idle
Pick a station
Nothing highlighted, no number, no Advance/Stop nav — just a prompt and the grid. A tap on any station starts it for the set run time. One touch, no confirm.

      
Running
Step, jump, or stop
The station name headlines, with its number above and a single amber countdown below — no redundant bar or labels. Advance jumps immediately, the grid jumps anywhere, and Stop closes everything and returns to idle.

      
The one setting
Auto-advance
Off (default): a station runs its time and stops. On: when the time ends it rolls into the next station and keeps going — start at station 1, walk the yard, and it stops on its own after the last.

      
Run time = the timeout
One value, also the safety cap
Every station opens with that time as its hard limit, so the controller auto-closes it even if the panel drops off. Nudge it up while a station's running and that station restarts at the new time — an easy extend. No separate cap, no pause.

    

  


  

    
03 Fits your system, stays quiet

    

      
Scales to station count
Grid wraps, never shrinks
The grid reads the live station list, so nothing's hardcoded. 12 or fewer sit in one row; more split into two balanced rows — your 14 as 2×7, the full 24 (with your extender) as 2×12 — with the pills staying finger-sized. Try Show 24 stations.

      
Sleeps when idle
Dark after 5 min, on while running
Idle and untouched for 5 minutes, the backlight blanks and wakes on the first touch — easy on backlight life and glare in the garage. While a station runs, the screen stays lit. Try Preview idle sleep.

    

  


  

    
04 Every action → one call

    
The panel keeps no privileged state; it drives the same endpoints your dashboard uses and reconciles to the controller on a poll. t is the run time in seconds.

    

      
ActionCall(s)Notes

      
        
Load stationsGET /jnNames + disabled bits build the grid — nothing per-install.

        
Poll statusGET /jcEvery ~2s while running. sn = on, ps = remaining. Truth for the countdown + highlight.

        
Run / jump to station nGET /cm?sid=n-1&en=1&t=RTTimed on; t is what makes it fail-safe.

        
Advance / Jump…&sid=cur&en=0 → …&sid=next&en=1&t=RTOff-then-on, back-to-back.

        
Extend (run time ±)…&sid=cur&en=0 → …&sid=cur&en=1&t=RT'Restart the current station with the new time (the controller ignores a bare re-on).

        
StopGET /cv?rsn=1All off, back to idle.

      
    

  


  

    
05 Guardrails

    

      
Connection
Top-bar status, self-heals
Controller unreachable → the status pill turns amber/red (Reconnecting, Controller offline, or Auth error) and the panel stops driving; any open station still auto-closes at its run time. On reconnect, /jc re-syncs the highlight. Try Cycle connection state.

      
Missing stations
Skipped automatically
Disabled/absent stations (from /jn + nstations) drop from the grid, so Advance never lands on a dead one. Works across the extender.
