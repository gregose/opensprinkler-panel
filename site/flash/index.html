Flash the OpenSprinkler panel firmware

Install the latest OpenSprinkler Panel firmware straight from your browser. Connect the panel over USB-C, then click Install.

Chromium browsers only. This flasher uses WebSerial, so it works in Google Chrome or Microsoft Edge. Firefox and Safari are not supported. The first install erases the flash. If the board's port doesn't appear, install the CH340 or CP210x USB-serial driver.
